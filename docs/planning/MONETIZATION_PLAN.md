# 安心圈 HavenCircle 營收策劃案（暫緩，之後再做）

> 狀態：**規劃完成、暫緩實作**（2026-07-19 定案）。使用者決定先做營運分析，付費留待日後。
> 方向已定：**純 freemium 訂閱、不接廣告**（保住零追蹤定位）。核心安全警報**永久免費**（倫理＋Apple 審查）。
> 本案已過三版發散 + premortem + 對抗驗收（fresh-context reviewer 抓出 8 個硬傷，已納入下方修正）。

## 前提與賭注（任一為假整案要改）
1. **賭「平安期也有人回來開 App」**：訂閱要「每月都覺得值」，但災害示警是低頻的。⚠️ 程式目前**沒有背景更新**、連「即時」都是前景觸發，此賭注證據薄弱 → 所以下方 **Step 0 先驗留存**。
2. **賭「有足夠家庭要守護 4 人以上或多個據點」**：付費動機來自規模（三代同堂、長輩獨居他處）。
3. **賭「對安全付費，用戶願意」**：而非「安全本來就該免費」。

## 建議路徑（分階段）

### Step 0（最先、近零成本）——先驗留存，不要先蓋付費牆
用營運分析（DAU/MAU、留存、漏斗）量「平安期有沒有人回來」。
- 留存夠 → 進 Stage 1。
- 留存崩 → **先做日常價值鉤子（背景更新）再談收費**，否則任何訂閱都 churn 爆。

### Stage 1＝個人年訂 freemium（改良版）
- 免費：核心警報全開＋**6 成員**／2 圈／1 關心區域／30 天歷史／看家人安否（基本協作免費）。
- 進階（**年訂為主**＋試用）：多圈／**多關心據點**／完整歷史／即時圈長時分享／所在地進階資料源即時推播（＊僅非安全核心的加值資料）／自訂靜音時段。
- **拿掉**「通知頻率『大』當付費點」（反功能）；小/中/大維持全免費。
- 價格：**估計** 年訂 NT$690（淨約 NT$587，Apple 抽 15% Small Business）、月訂 NT$90 備選。**須先查台灣同類行情再定**。

### Stage 2＝家庭方案（Stage 1 驗證有人付費後才做）
一人付費全家解鎖。動工前先做 `FamilyEntitlement`（寫進 CKShare 共享 zone、成員端 OR 判定）**最小技術 demo** 去風險。⚠️ 付費者不一定是 zone owner、CKShare 跨帳號無法在模擬器/單帳號驗——別低估。定價等 Stage 1 資料。

### 後備軸＝B2B 社區/物業（暫緩）
消費端轉換太弱才啟動，**啟動前須先設公司實體＋責任險**（住戶被誤標平安卻出事的究責，對無實體獨立開發者是結構性風險）。

## 對抗驗收的關鍵修正（已納入）
- 訂閱 vs 低頻本質的張力 → 改**年訂為主**（保險型心智）、且 **Step 0 先驗留存**。
- 付費者/受益者錯配 → Stage 1 牆改設在「對付費者本人就有價值」的功能；基本協作（看家人安否）維持免費。
- 免費成員上限 3→**6**（裝得下完整家庭，牆別設在啟用前）。
- **StoreKit 從零**：Stage 1 真正第一步＝建整層 IAP＋entitlement＋gating，且 entitlement 要**離線判定**、付費檢查失敗**絕不降級安全功能**。
- 定價一律看**淨收**（扣 Apple 抽成）；所有數字皆估計、需行情佐證。
- **Supporter tier 徽章＝數位商品＝須走 IAP、照抽**，非零成本、非 App 外捐款；且**不可與訂閱牆同時上**（污染轉換訊號），排序在後。
- 法務：對安全功能收費 → 注意義務上升，文案須明標「輔助參考、非替代 110/119」。
