# 憑證安全處理紀錄

本文件不保存任何 API key、Token、密碼或私鑰。

## 安心圈資料流

```text
官方／新聞來源
  → Mac Mini 爬蟲與 AI 分類（憑證僅在這裡）
  → HavenCircle 網站 API（只保存整理後的事件）
  → iOS App（只讀取事件資料並在裝置端比對警戒圈）
```

## 憑證放置規則

- Gemini、ProxyCLI、官方資料來源 key：只放在爬蟲主機的獨立權限 `600` 檔案，不進 Git、不進 App、不進公開網站檔案。
- 網站的 APNs、FCM、資料接收憑證：只放在伺服器端不受 Web 存取的設定檔，不進 Git。
- iOS App 不可包含任何可向上游 AI 或付費服務發出請求的祕密；它只能呼叫 HavenCircle 網站公開的事件 API 或有限權限代理。
- 已經貼進聊天、文件、Issue 或 commit 的憑證一律視為外洩，必須先撤銷並重發，不能搬到任何新檔案繼續使用。

## 免費／付費 Gemini 隔離

爬蟲依序使用 ProxyCLI 免費路徑、獨立免費 Gemini 池、獨立付費 Gemini 池與規則分類。每一池使用不同 key 檔與獨立用量帳本；免費層失敗不會自動用付費 key，付費層仍須明確開啟與設定月費上限才可能呼叫。
