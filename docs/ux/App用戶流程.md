# 安心圈 — 完整用戶流程

> 逐畫面描述整個 App：使用者看到什麼、點哪裡、彈出什麼、字寫什麼。文案為目前程式碼的實際字串。
> 新手流程的更細節版見《新手流程說明.md》。

---

## 0. 資訊架構總覽

```
App 啟動
 ├─ 全新使用者 → 新手流程（乾淨地圖著陸 → 授權定位 → 地圖脈動帶領）
 └─ 老使用者 → 主畫面（底部 3 分頁）
      ├─ 🛡️ 安心（預設落點）─ 全家平安總覽、提醒中心、回報平安
      ├─ 🗺️ 安全地圖 ─ 警戒圈、事件、資源、家人位置
      └─ 👥 家人 ─ 警戒圈管理 ⇄ 安否回報（頂部分段切換）
 設定＝全域彈出視窗（從安心頁右上角齒輪開），不是分頁。
```

三條「事件 → 人」的核心閉環：
1. **警報進來** → 通知 → 點開直達事件詳情 → 回報平安給家人。
2. **家人出事** → 長按通知「詢問是否平安」→ 對方回報 → 已讀回條。
3. **自己出門** → 開即時位置分享 → 家人地圖上看得到你。

## 1. 首次啟動（新手流程）

### 1-1 乾淨地圖著陸
打開 App 第一眼：一片降噪地圖（無店家標記），定位**台北車站**。畫面中央一張卡：
- 👆 呼吸的點擊手勢
- **歡迎來到安心圈**／災害來的時候，讓家人知道你在哪裡、也讓你知道家人平安。
- 藍字提示：**點一下地圖，讓安心圈找到你**

**點畫面任何一處** → 跳 iOS 定位權限框。
- **允許** → 鏡頭滑到你的位置，卡片變「✓ 找到你了」＋大按鈕「**開始使用安心圈**」。
- **不允許** → 留在台北車站，卡片變「**沒有定位也沒關係**」＋「前往設定開啟定位」／「先看看，稍後再開」。不卡死。

### 1-2 進入地圖＋預設警戒圈
完成著陸直接落在「安全地圖」分頁：
- 自動建好「本人」成員（暫名「我」）＋一個**預設 1 公里警戒圈**（圈心＝你的位置，拒絕定位則台北車站）。
- 頂部狀態膠囊「警戒圈平安」。

### 1-3 帶領（目標自己動、幾乎無字）
不用文字卡，讓目標自己動：
1. **你的警戒圈**：聲納式雙圈從圈心向外脈動，頂端藍色小膠囊「**你的守護範圍**」。
2. **附近事件**（僅圈心 2.5 公里內真的有事件時）：紅點用紅色脈動圈標出＋小膠囊「**附近的事件**」；沒有就跳過。

點畫面任意處進下一段；底部小字「輕點繼續」。走完結束，之後不再出現。

### 1-4 之後的一次性提示
- **第一次切到「安心」分頁**：中央小卡「**看全家平不平安**」——點畫面任意處關。
- **第一次切到「家人」分頁**：中央小卡「**在這裡連結家人**」——點畫面任意處關。
- **第一次點開任一事件、關掉詳情後**：中央小卡「**點你的警戒圈，就能拖著調整範圍**」——只出現一次。

> 「選家庭身分」（爸爸/媽媽/兒子/女兒/阿公/阿嬤 六方塊）已做好但**暫不自動出現**——等家人介面重寫時接回。

## 2. 安心分頁（預設落點）

從上到下：

| 區塊 | 看到什麼 | 點了會怎樣 |
|---|---|---|
| **狀態主卡** | 全平安＝呼吸動效的守護環＋「警戒圈一切平安」；即時圈逾 15 分鐘未更新＝琥珀「部分即時圈待更新」；事件命中警戒圈＝紅色「N 件事件靠近警戒圈」＋「查看地圖」鈕 | 「查看地圖」→ 切到安全地圖分頁 |
| **家人列**（有成員才顯示） | 每位家人：名字＋狀態點；圈內有事件顯示事件標題與距離，否則「圈內無事件」＋最後回報時間 | 只有「命中事件」的列能點 → 彈出**事件詳情** |
| **背景看守摘要** | 一行：「背景看守中：未驗證線索 N・其他區域 N・區域警報 N」 | 整列可點 → 進**提醒中心** |
| **回顧** | 「回顧過去 30 天」 | → 歷史頁 |
| **底部固定大按鈕** | 「**回報我平安**」 | 彈出**安否回報**視窗 |

右上角齒輪 → 彈出**設定**。

### 2-1 提醒中心（事件列表）
進入：安心頁「背景看守摘要」，或點通知直達。分組由上到下：
1. 頂部**迷你地圖**（進行中事件；點空白放大到地圖分頁、點標記開詳情）
2. **區域警報**（天災/公共安全/民生/交通分組，各組最多 3 則可展開）
3. **需要注意**（官方確認且落在警戒圈內，永遠展開）
4. **未驗證線索**（預設收合）
5. **附近動態**（圈外 30 公里內官方事件，收合）
6. **全台其他示警**（摺疊）
7. **已結束**（收合，最多 20 則）

點任一則 → 彈出**事件詳情**。右上角「演練」→ 防災演練模式。

### 2-2 事件詳情（全 App 共用：安心頁、提醒中心、地圖都開它）
- **狀態列**：已結束／官方確認／未驗證＋一句提示。
- **事件說明**：官方原文或 AI 整理。
- **提醒判斷**:為什麼你會收到——列出命中的警戒圈與距離。
- **AI 影響分析**：按鈕「AI 分析：這起事件對我的影響」→ 生成 100-150 字個人化說明＋免責＋「重新分析」。
- **安否**（進行中事件才有）：命中自己的圈 →「回報我平安」「尚未脫離危險」；命中家人的圈 →「詢問 X 是否平安」。按下即送出，顯示「已送出回報」。
- **資訊**：類型、概略位置、嚴重度、時間。**來源**：附原始連結。
- **緊急應變**：最近避難所＋急救醫院，各有「導航」（開 Apple 地圖）。
- **底部動作**：「隱藏此裝置的相似提醒」「回報此事件在我這裡已解除」（有確認框）「撥 110」「撥 119」。

### 2-3 安否回報（底部「回報我平安」／家人分頁切「安否回報」）
- 補充說明文字框（可空）。
- 「附上我的目前位置」開關（**預設關**，開才要定位；只存地區名不存精確座標）。
- 三顆狀態按鈕：「**我平安**」「**尚未脫離危險**」「**需要協助**」→ 按下即送出。
- 下方**家人回報清單**：狀態圖示＋名字＋時間＋備註＋位置＋「已讀：X、Y」——你看過對方的回報會自動變已讀，對方看得到（已讀回條）。
- 右上角「邀請家人」→ 彈出邀請碼視窗（見 4-1）。

## 3. 安全地圖分頁

### 3-1 地圖上有什麼
- **你的警戒圈**（藍圈）與家人的圈；即時圈過期會轉灰並標示。
- **事件標記**：圖示＝類型、顏色＝可信度（紅＝官方確認、琥珀＝確認中）。
- **家人位置**：開即時分享的家人＝藍點；沒開的顯示最後一次回報位置。
- 可開關圖層：避難所、醫院、空氣品質、治安統計（預設全關）。
- 頂部安全摘要膠囊；底部附近事件卡片列；右下角「乾淨模式」把所有浮層收掉只留地圖。

### 3-2 互動
| 動作 | 結果 |
|---|---|
| 點事件標記 | 底部彈出摘要卡（半高）→「查看完整資訊」展開成完整事件詳情 |
| 點**自己的警戒圈** | 圈邊出現**可拖把手**＋半徑數字（如「1,000 公尺」）→ 拖大拖小（200–5000 公尺），放手即存；再點一次圈退出 |
| 點區域警報塗層區 | 彈出區域警報詳情 |
| 右上工具列 | 家人切換（全家/單人）、圖層與類型過濾、暫停提醒 |

## 4. 家人分頁（頂部分段：警戒圈 ⇄ 安否回報）

### 4-1 邀請家人（Firebase 8 碼邀請碼）
列表頂部固定「邀請家人加入安心圈」——點了自動建立家庭圈（第一次）並彈出邀請視窗：
- **8 碼邀請碼**大字＋複製鈕
- **QR code**（對方掃了輸碼）
- 「用訊息或 AirDrop 分享」

**加入端**：點「用邀請碼加入家庭圈」→ 輸入 8 碼（自動轉大寫）→「加入家庭圈」→ 成功畫面「已加入家庭圈！現在可以在『安否回報』跟家人互報平安」。

### 4-2 即時位置分享（本人）
列表頂部第二區塊：開關「**分享這支手機的位置**」。
- 開啟 → 要求「永遠允許」定位 → 立即發布一次位置；顯示警戒半徑調整（300–3000 公尺）＋位置新鮮度（逾 15 分鐘標示過期）。
- 關閉 → 「即時位置分享已停止」。狀態與停止入口永遠明示（同意式，不偷偷）。

### 4-3 成員與圈管理
- **成員列表**：每列＝名字＋即時圈/固定圈數量；點列進**成員詳情**；左滑刪除。
- 右上 **＋**：「新增家人」「新增重要地點」→ 填名字存檔後**自動接著**彈出警戒圈編輯器（一氣呵成）。
- **成員詳情**：本人＝直接放位置分享開關；家人＝即時圈狀態（沒開顯示「等待這位家人在自己的手機上開啟位置分享」）＋固定圈清單（點編輯）＋「新增固定圈」。
- **警戒圈編輯器**：地點名稱、地址搜尋（自動 Apple Maps 搜尋）或「把目前位置設為固定地點」、提醒半徑、行政區、「只在特定時段提醒」（一週七天＋起訖時間）→ 儲存。

## 5. 設定（全域彈出視窗）

由上到下：
1. **帳號卡**：名稱＋email＋帳號狀態 → 帳號詳情
2. **升級 Guardian+** → 付費方案頁
3. **防災問答** → AI 助手
4. **個人化**：個人資訊／提醒設定（通知頻率小/中/大）／外觀（跟隨系統/淺/深）
5. **資訊與隱私**：法律與隱私／資料來源／匿名使用統計開關／關於／重看新手教學／重看功能導覽
6. **刪除帳號與所有資料**（二次確認）
7. （Debug 版限定）**示範與開發**：模擬警報通知、載入歷史/六災難示範、**重跑新手流程**、APNs 權杖
8. 底部免責：「安心圈不是緊急服務⋯撥打 110 或 119」

## 6. 通知與 Widget 進入路徑

| 入口 | 行為 |
|---|---|
| **點警報通知本體** | 開 App → 切到安心分頁 → 推入提醒中心 → **自動彈出那一則事件詳情** |
| **長按通知的快速按鈕** | 「回報我平安」「尚未脫離危險」「詢問是否平安」——**不開 App**，背景直接送出回報 |
| **Widget 點擊** | 依區塊深連結：警報→提醒中心／地圖→地圖分頁／家人→家人分頁 |
| **無聲推播**（伺服器偵測新官方警報） | 背景喚醒 App 刷新資料，相關才發本機通知——比對在裝置上做，位置不上傳 |

## 7. 已知未收尾（寫給自己與接手者）

- **舊教學殘留**：舊六步精靈（OnboardingView）與黑幕聚光燈導覽（FeatureTour）還在，設定頁「重看新手教學／功能導覽」仍指向它們；新手流程已改走新版。待整條新流程定案後移除並更新設定頁入口。
- **選家庭身分**：六方塊畫面（RoleSelectView）已做好、已從自動流程解耦，等家人介面重寫時接回。
- **用語不一致**：邀請碼機制已是 Firebase，但家人頁/設定頁多處文案仍寫「iCloud」帳號狀態，遷移收尾時要統一。
- **實機待驗**：拖圈手感、真實冷啟動全鏈路（點地圖→授權→脈動帶領）。
