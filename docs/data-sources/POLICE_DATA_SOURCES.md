## 逐項查證細節（已查證官方頁面）

### 1. data.taipei（台北市）—【已查證官方頁面】

**臺北市住宅竊盜點位資訊**（data.taipei，id=68785231-d6c5-47a1-b001-77eec70bec02；亦鏡射於 data.gov.tw/dataset/130312）
- 收錄期間：民國104年1月至115年5月（即2015-01至2026-05），持續累積中
- 最後詮釋資料更新：2026-06-04 16:11
- 欄位：編號、案類、發生日期、發生時段、發生地點
- **地理精度實測**：直接下載 CSV 樣本確認，地點欄位形如「大安區忠孝東路X段91~120號」——門牌號碼被模糊化為30號一個區間，**無座標欄位**。這是有意的隱私處理（新聞稿標題即為「治安透明 市民安心」，2015年上線時同步強調保護個資）。
- 授權：政府資料開放授權條款
- 提供機關：台北市政府警察局刑警大隊（聯絡人 陳勇行）
- 免費、CSV下載＋API預覽皆可

**其他台北市相關資料集（查證後排除）**：
- 臺北市竊盜案件（id=607dd52a…）：年度**統計數字**（發生數/破獲數/破獲率），無地點欄位，非點位資料
- 臺北市暴力犯罪（id=13fba49a…）：同樣是年度統計數字，含強盜搶奪案件數，但無地點欄位
- 臺北市政府警察局主題專區（id=0b13eb52…）：只是連結索引檔，非資料

**結論**：台北市目前唯一具地理意義且持續更新的，只有「住宅竊盜點位資訊」一項，案類僅限住宅竊盜。

### 2. 新北市 data.ntpc.gov.tw —【已查證官方頁面＋實際下載樣本】

**犯罪資料**（id=8a32c6b5-46fc-4fac-b3a4-317b9998bfd7）
- 提供機關：新北市政府警察局
- 更新頻率：每季
- 格式：CSV/JSON/XML，OpenAPI 可介接
- **實測 API 回傳樣本**（`GET /api/datasets/8a32c6b5.../json`）：
  ```json
  [{"type":"住宅竊盜","year":"107","date":"1070401","location":"新北市淡水區"},
   {"type":"機車竊盜","year":"107","date":"1070401","location":"新北市"}]
  ```
  確認地理精度為「縣市＋區」，機車竊盜若地點不明時僅到縣市層級，**無座標、無地址**
- 授權：政府資料開放授權條款-第1版

**竊盜案件**（id=5b2f3a6b…）：查證後為**單純統計數字**（依年份、性別分類），完全不含地理欄位，跟資料集名稱容易誤導——這不是點位資料。

**結論**：新北市的「犯罪資料」其實與全國性 data.gov.tw/14200 是同源資料（縣市警局上傳全國平台），精度一致（區級）。

### 3. data.gov.tw 全國平台 —【已查證官方頁面】

**犯罪資料**（dataset/14200，內政資料開放平臺 oid=AC4C5CF9-682A-450A-8405-45706B8C9588）
- 提供機關：內政部警政署（全國彙整，含六都及其他縣市）
- 更新頻率：**每季**（初步統計，供參考）
- 格式：CSV/JSON/XML，40+個檔案，涵蓋民國104年至114年各季
- 欄位：type（案類）、oc_year（發生年度）、oc_date（發生日期）、oc_county（發生縣市）、oc_region（發生鄉鎮市區）
- 涵蓋8案類：毒品、強盜、搶奪、住宅竊盜、汽車竊盜、機車竊盜、強制性交（自107年10月起新增組織犯罪）
- 資料備註：機車竊盜案件若發生地在路界、縣界或報案地點不明確，僅顯示縣市（不到區）
- 授權：政府資料開放授權條款-第1版
- 最後更新：2026-04-22

**這是全國唯一具規模、持續更新、多案類、有明確地理欄位（縣市＋鄉鎮市區）的資料集**，是新北市、部分縣市犯罪資料的上游來源。

**歷年犯罪資料統計數據**（dataset/24305）：近10年彙總（發生數/破獲數/破獲率），**無地理細節**，是統計表非點位。

**114年整體治安情勢**（dataset/177118）：PDF格式全國彙總報告（詐欺32.14%、竊盜12.56%等占比），非結構化資料，不可程式化解析地點。

**桃園市住宅/機車/汽車竊盜點位**（dataset/26276、26279、26280）：
- 三個資料集皆標註「**資料集已下架，此為歷史資料留存**」
- 欄位含 lat、lon（**座標級**，是六都中曾經精度最高的資料）
- 原上架於2016年，最後一次詮釋資料更新為 2024-07-09，代表官方已停止維護
- 結論：**此路目前不通**——桃園已不再提供新資料，只能拿2016–2023年的歷史快照做「過去式」示意，無法承諾未來更新

**婦幼安全警示地點**（dataset/6247）：全國性＋部分縣市（嘉義縣、台中市、台北市、桃園市、澎湖縣）子集。官方明確聲明「避免標示個別商（住）家及地址，以符合個資法規定」，故只到路段/區域級，無座標。授權CC-BY 4.0，不定期更新。這是「警示區域」而非「案件發生點」，性質不同於竊盜點位。

**內政部警政署 OPEN DATA 列表**（www.npa.gov.tw，共126筆資料集，逐頁查證前15筆代表性項目）：
- 帶地點/座標的資料集多為「設施地點」而非「案件發生地點」：各縣市警察機關地址、婦幼安全警示地點、測速執法設置點、拖吊保管場、海嘯警報臺座標等
- **未發現**任何全國性、案件級、帶座標或村里級的即時或近即時治安點位資料集
- 165打詐儀錶板打擊詐欺犯罪執行成效（dataset/172159）：全國彙總統計（查緝團數、金額），**無地理分層**，且165dashboard.tw網站本身未見公開API或JSON端點說明（僅網頁儀表板），此路不通
- 車輛竊盜/車牌失竊查詢（dataset/9365）：這是**查詢工具**（輸入車牌回傳失竊紀錄），非批次資料集，且**無地理資訊**

### 4. 六都以外：桃園、台中、高雄 —【已查證官方頁面】

- **桃園**：見上，唯一曾有座標級點位資料的縣市，但已下架僅存歷史檔（2016-2023）
- **台中**：臺中市犯罪統計資訊（opendata.taichung.gov.tw）為月別統計數字，**無地理欄位**，此路不通
- **高雄**：高雄市各分局轄區重要指標（dataset/87239）為「分局轄區」層級聚合統計（人口、面積、刑案發生/破獲數），**非點位、無座標**，只能做「分局等級」色塊圖，無法做熱點地圖

### 5. 村里犯罪統計 —【查證結果：查無此類公開資料集】

- 搜尋內政部/警政署/中華民國統計資訊網等管道，**未查到任何達到「村里」地理精度的犯罪統計公開資料集**
- 目前全國性資料（data.gov.tw/14200）最細地理單位為「鄉鎮市區」（oc_region），比村里粗一級
- 台北市住宅竊盜點位資訊雖有「地址」（模糊化門牌區間），細於鄉鎮市區，但不是以行政村里為統計單位，且僅台北市單一縣市、單一案類

## 此路不通清單（含原因）

| 項目 | 原因 |
|---|---|
| 桃園市座標級竊盜點位（住宅/機車/汽車） | 已於官方頁面明確標註「已下架」，2024-07後未再更新，只能用作歷史快照 |
| 165打詐儀錶板 | 網站僅為視覺化儀表板，無公開API/JSON端點；且其資料集（dataset/172159）為全國彙總的「打擊成效」統計，非空間性犯罪點位 |
| 台中市犯罪統計資訊 | 僅月別總數，無任何地理欄位 |
| 高雄市各分局轄區重要指標 | 只到「分局轄區」聚合層級，無點位座標，也無法回推到區/村里 |
| 村里級犯罪統計 | 查證全國、警政署、內政部各平台，均未發現此地理精度的公開資料集 |
| 內政部警政署 OPEN DATA（126筆） | 逐頁篩檢後，帶座標的資料集皆為「治安設施地點」（警局地址、測速照相、拖吊場等），無「案件發生地點」座標資料 |

## 結論：能否支撐「歷史治安熱點圖層」？

**部分可行，但涵蓋不均、精度不一致，需分層設計：**

1. **全國骨幹層**：data.gov.tw「犯罪資料」（dataset/14200，警政署）——唯一涵蓋全台、多案類（住宅竊盜/汽車竊盜/機車竊盜/搶奪/強盜/毒品/強制性交/組織犯罪）、持續每季更新的資料源。精度只到「鄉鎮市區」，做不出街廓級熱點，但足以支撐「行政區治安燈號／深淺色塊」等級的參考圖層，覆蓋全台22縣市。

2. **台北市加值層**：data.taipei「臺北市住宅竊盜點位資訊」——地址級（模糊化到門牌30號區間），精度遠優於全國資料，且持續更新（最近一次2026-06），可疊加在全國圖層上做台北市的精細熱點，但僅限住宅竊盜一類、僅限台北市。

3. **桃園歷史層（選用）**：曾有座標級點位資料，但已停更，只能標註「2016-2023年歷史資料」，不建議作為主要資料源，僅可作為過去式示意圖。

4. **台中、高雄**：目前公開資料做不出空間熱點圖，只能做「分局／全市」層級的文字統計摘要，不建議放進地圖圖層。

**兩項推薦資料集**：
1. **第一名**：data.gov.tw「犯罪資料」（[dataset/14200](https://data.gov.tw/dataset/14200)，警政署，全國，季更，縣市+鄉鎮市區精度，CSV/JSON/XML API）——作為 HavenCircle 治安圖層的主骨幹，唯一具全國覆蓋能力。
2. **第二名**：data.taipei「臺北市住宅竊盜點位資訊」（[連結](https://data.taipei/dataset/detail?id=68785231-d6c5-47a1-b001-77eec70bec02)，台北市警局，地址級模糊化，持續更新）——作為台北市用戶的精細加值圖層。
